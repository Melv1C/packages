# VS Code settings and extensions

The package ships canonical workspace snippets for Oxc formatting and the Vite+ extension pack.

**Copy into your repo:**

```bash
mkdir -p .vscode
cp node_modules/@melv1c/toolchain/vscode/settings.json .vscode/settings.json
cp node_modules/@melv1c/toolchain/vscode/extensions.json .vscode/extensions.json
```
